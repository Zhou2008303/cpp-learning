# LeetCode 01 两数之和

日期：2026-10-05

平台：LeetCode 用的是 class + vector 模板，我还没学到。
    所以先用**洛谷的形式**（完整程序 + cin/cout）在本地练。

## 题目在问什么

在一堆数字里找出两个数，让它们加起来等于目标值，然后输出这两个数的位置。

## 算法

两层循环：
- 外层 `i`：拿起第 i 个数
- 内层 `j`：试它**后面**的每个数

`j` 从 `i + 1` 开始。

## 我踩的 4 个坑

1. **`int m;` 没输入就直接用** → 循环次数是内存里的垃圾值
   修：先 `cin >> m;` 再读数组

2. **`using namespace stf;`** 拼错了 → 应该是 `std`

3. **`j` 从 0 开始** → 两个后果：
   - `i == j` 时自己和自己相加（3 + 3 = 6，会输出 `[0,0]`，但题目要两个不同的位置）
   - `(1,2)` 和 `(2,1)` 是同一对，会重复输出
   修：`j = i + 1`，只试后面的 —— 一次解决两个问题

4. **找到后没停** → 继续把所有组合试完，打印一堆
   修：找到就 `return 0`

## 复杂度

- 时间：O(n²)（两层循环）
- 空间：O(1)
